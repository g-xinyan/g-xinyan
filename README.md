### 🚀 Featured Projects

#### 🔮 熬夜养生搭子 — AI Agent 健康管理产品
> 面向 1.2 亿熬夜人群的 AI 养生助手，独立从 0 到 1 研发

[![Live Demo](https://img.shields.io/badge/Live_Demo-Visit-3ECF8E?style=flat-square)](https://soft-entremet-6e6ff8.netlify.app/)
[![Repo](https://img.shields.io/badge/Repo-View_Code-181717?style=flat-square&logo=github)](https://github.com/g-xinyan/stay-up-late-health-buddy-based-on-AI-Agent)

- **技术架构**：RAG 检索增强 + Prompt Engineering（7 模块 System Prompt / Few-shot / 隐式思维链）+ Tool Calling
- **知识库**：102 条养生知识条目，5 维 Reranker（语义相似度 45% + 关键词重合 25% + 内容命中 15% + 时令加成 + 体质加成）
- **数据驱动**：Supabase 实时埋点，6 节点数据追踪，北极星指标「周健康任务完成数」
- **效果**：对话平均轮次提升 32%，用户满意度从 61% → 79%

#### 🌊 FathomNet 2025 海洋物种图像分类
> Kaggle 竞赛 · 基于深度学习的海洋生物细粒度分类

[![Repo](https://img.shields.io/badge/Repo-View_Code-181717?style=flat-square&logo=github)](https://github.com/g-xinyan/fathomnet2025-marine-classification)

- 基于 FathomNet 数据集，训练神经网络对水下生物进行物种级分类，评估指标为生物分类树上的层级距离
- 对比 ResNet、Transformer、EfficientNetV2 等多种架构，最终 EfficientNetV2-M 取得最优成绩（层级距离 3.21）
- 涵盖数据预处理、模型训练、超参调优全流程

#### 📊 电商推荐系统召回策略评估与优化
> 毕业设计 · 基于 OTTO 公开数据集（4000 用户会话，千万级商品）

- 构建加权召回率北极星指标，按会话长度 / 时间窗口 / 兴趣漂移多维度归因
- 完成 9 类召回策略横向验证，冷启动场景引入聚类召回与 Look-alike 策略
- 召回率优化至 0.4965，提升约 27%

#### 💳 信贷风险预测与客户差异化授信策略
> 项目负责人 · 融合多算法的特征选择 + 客户分群 + 不平衡建模

- 3 种特征选择方法降维至 35 维，保留 92%+ 信息增益
- K-Means 划分 4 个风险层级，支撑差异化授信
- 最优模型 AUC 0.72 / KS 0.43
